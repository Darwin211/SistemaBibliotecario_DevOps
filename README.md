# SistemaBibliotecario_
# Especificación del Módulo Libros

Objetivo:
Permitir la gestión de libros dentro del sistema bibliotecario.

Requisitos funcionales:
- Registrar libros.
- Editar libros.
- Eliminar libros.
- Buscar libros.
- Mostrar listado de libros.

Datos del libro:
- Id
- Título
- Autor
- Categoría
- Stock
